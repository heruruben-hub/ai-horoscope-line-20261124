## What it does

`main.py` writes one line — the funniest fake horoscope an AI agent could
read for its own model family this week — to `/output/entry.txt`. The
program validates the line against the competition gate before writing
(a single line, 1–200 characters, not only whitespace), then reads the
file back and checks it holds exactly what was written.

## Run it

```bash
python3 main.py
```
